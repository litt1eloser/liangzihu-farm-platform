# M2 GIS R03 V1.2：轻量概要卡 + 按需展开完整详情（交互规则）

> **日期**：2026-11-02
> **地位**：本文档是 R03 的 V1.2 修订，独立归档，不覆盖 V1/V1.1 原始文件。产品已确认采用方案 A「轻量详情卡 + 按需展开」（原型见 `原型/m2-r03b2`，R03-B2 定稿报告），不再进行 A/B 比较。
> **实施约束**：复用现有 `DetailPanel` 与数据请求逻辑，只增加概要/完整展示状态；不修改 R01/R02 已验收的数据可信性、权限、业务字段、空态、CAD 来源及设施身份判断规则。

## 1. 详情面板双态

- **概要卡（默认）**：选中对象即出现。内容为对象名称、类型徽标、范围/位置状态徽标、所属位置与关键业务摘要（现有 summarySlot：农田面积/当前生产/生长阶段，塘口面积/当前养殖/指标槽位，水闸实际开度/数据上报，泵站泵组概况/数据上报）。高度随内容自适应，不出现大面积空白。操作：「查看详细资料」「定位当前对象」（有定位能力时）「×」。
- **完整详情（按需展开）**：点击「查看详细资料」就地展开为现有完整结构（摘要 + 三标签 + 标签体 + 底部操作）。面板高度随内容增长，上限受控（桌面 `calc(100% − 96px)`，手机 66% 地图高），超出内部滚动，底部操作条吸附可见。支持「收回概要」返回概要卡。
- **资料依据**：始终默认折叠，不因展开完整详情自动展开。
- 概要态点击顶部当前告警的「查看」：自动展开完整详情并定位到相关记录原事件（沿用 F06 行为）。

## 2. 状态流转规则

- 新选中对象（含会话恢复）→ 概要卡。
- 同类对象切换（F02 口径，含水闸/泵站各自为类）→ 保留展开状态与当前标签、记录筛选。
- 跨业务类切换（含 gate↔pump、进出片区/机动设备）→ 回概要卡 +「基本信息」。
- 关闭（× / Esc）→ 面板消失，密度重置为概要。
- 展开、收回、切换标签、关闭均**不得**改变地图中心与缩放。

## 3. 资源目录协同折叠（窄屏桌面 761–1100px）

- 详情面板由关闭变为打开时，若目录处于展开状态 → 系统自动折叠为工具栏「› 目录」拉手。
- 系统自动折叠与用户手动操作严格区分：用户手动展开/收起目录后，普通状态更新（包括再次选择对象）不得强制折叠目录。
- 关闭详情时，仅当目录是本次详情期间被系统自动折叠且用户未手动操作过时，恢复为展开；否则保持用户最后状态。
- 手机端（≤760px）目录为覆盖式抽屉，沿用既有行为，不参与桌面协同折叠。

## 4. 地图目标避让

- 仅「选中新对象/片区」与「定位当前对象/竣工图范围/全场视图」执行定位；展开、收回、标签切换、关闭详情均不触碰视口。
- 定位留白按**实际**详情面板尺寸与可视地图区域计算：桌面右侧留白 = 面板实测宽度 + 32px；手机底部留白 = 面板实测高度 + 24px（上限 70% 视口高）。
- 选中定位后目标边界应完整落在未被面板遮挡的地图区域内。
- 手机端展开完整详情不移动地图；目标被遮挡时由用户通过「定位当前对象」按需重新定位。

## 5. 响应式

- ≥1440px：右侧浮动卡，概要/完整均按内容决定高度，不占满整屏。
- 1024px：顶部导航单行收敛（副标题隐藏、链接可横滑、不换行）；目录协同折叠；目标保持可见。
- 390px：底部轻量卡（≤58%）与底部完整卡（≤66%）；缩放控件移至顶部工具栏下方，不被底部卡遮挡；无横向滚动。
