# M2-A：二维卫星地图点位标注

项目目录：`/data/wfx/liangzihu-farm-platform`

请先阅读 AGENTS.md、README.md、现有 `/map-prototype` 源码、API 权限机制、PostGIS 数据结构和测试规范。

**目标：** 在已经验证成功的 OpenLayers + 天地图卫星原型中实现可持久化的点位标注，支持中文名称。

## 功能要求

1. 在地图旁新增“浏览 / 标点”工具栏。默认浏览模式；选择标点后，点击地图创建临时标点。
2. 弹出编辑表单，支持输入中文名称、可选备注，并显示经纬度。名称允许常见中文、英文及数字，不能为空。
3. 点击保存后，将点位保存到 PostgreSQL/PostGIS，采用 EPSG:4326 存储，经纬度顺序必须正确。
4. 保存成功后，在地图相应位置显示标记及中文名称。点击已有标点可查看详情、修改名称或备注，并可确认删除。
5. 保存失败时保留当前表单与临时标记，提示可理解的错误；取消或按 Esc 退出标点模式，不写入数据。
6. 页面刷新后自动读取已保存点位。初版可采用当前用户私有草稿模式，避免随意暴露给其他用户；不要未经授权修改正式农田边界和设备台账。
7. 新建独立、最小必要的点位数据表与接口。不要复用仅适合无人机航次疑点的 `flight_annotations`。沿用现有鉴权、事务、审计、迁移及输入校验规范。
8. 正确支持中文输入法（IME），避免输入拼音过程中表单意外提交、地图重绘或输入框失去焦点。
9. 保留 M1 的卫星图、中文注记、平移缩放、现有 Key 和初始定位。不修改正式 `/map` 和三维页面。

## 测试与交付

- 测试中文输入，例如“一号水泵”“长岭3号监测点”，保存后显示及数据库读取一致。
- 测试添加、编辑、取消、删除、刷新恢复、重复保存、网络错误、未授权访问及经纬度校验。
- 执行类型检查、生产构建、相关单元和数据库集成测试，以及实际浏览器操作测试。
- 根据仓库规范更新 README、CHANGELOG 和验收记录。
- 不使用模拟标记冒充真实数据库保存结果，不输出真实天地图 Key。

完成后请启动可访问的测试页面，提供测试地址、改动文件清单、数据库迁移情况、测试结果和已知问题，供用户手动验收。
