# D3.1 农场总览产品可用性修订验收记录

日期：2026-10-09。依据：[D3.1 修订命令](../../../计划/D3.1%20农场总览产品可用性修订.md)、[详细开发说明](../../../计划/D3.1%20详细开发说明.md)、[冻结产品 v1.0](../../../计划/产品定义与最终开发边界%20v1.0.md)。基线提交 `cf96b03e0ebdb353b78083ce963995df7e3b7ce4`。用户提供的[规划参考图](梁子湖规划参考-非测绘.jpg)仅作构图与空间层次参考，图像没有可靠 WGS84 顶点或经营权属数据。

## 实施与最小改动

- 总览默认真实模式；显式进入/退出演示，顶部持续标明合成数据。稳定 fixture 含 3 个虚构经营片区、5 块农田、3 个塘口、4 处设施、2 台机动设备、1 条演示提醒、2 条演示任务。统计由同一清单计算；`demo:` ID 和独立 OpenLayers 图层不进入正式 API。演示多边形采用近似展示锚点并用蓝色虚线表示，非测绘边界；演示设备位置非 GPS。
- “＋ 新增/管理”在真实目录及桌面折叠后的地图工具栏可见，手机可从目录操作。村庄复用 `RegionManagement` 与 `/api/v1/map-regions`；地块、塘口、设施复用 `/objects` 与正式边界草稿入口；实体设备在 `/devices` 补数据来源和设备登记薄表单，适用的农机关系仍去 `/machinery`。对象配置权限由原 API 返回决定，后端原资源级权限不变。
- 右侧详情按农场、片区、农田、塘口、设施、机动设备分开呈现。真实模式只显示可核实数量和现有告警/农事/测点概要，缺少作物、水质、状态或 GPS 时明确未知；版本、来源、时间和边界状态在默认折叠区。演示详情只提供退出演示入口，不生成真实业务链接或控制按钮。
- 对象台账支持 `facility` 正式主档登记；设施对象与实体设备仍是不同身份。现有 `devices.kind=physical` 不被用来伪造无人机/农机的完整业务分类。
- 无数据库迁移，未改变 `/map`、`/map-prototype`、`/terrain`、设备核实、农机绑定或控制规则；未向生产库写入模拟资料，未部署生产。

## 验收意见修订

- 演示片区关联只包含农田、塘口和固定设施；无人机与收割机只在并列的机动设备目录各出现一次。设备详情仍写明登记归属，单测和浏览器均核对目录不重复。
- 实体设备登记成功后，设备列表立即重新读取。隔离浏览器在不刷新页面的情况下看到新登记的无人机，数据库仍记录 `verified=false`。
- 合成图层锚点依据本轮浏览器卫星底图截图作岸线、道路和陆地关系的近似微调。规划参考图没有可测量坐标，图层继续统一标注“非测绘位置”，设备提示“非真实 GPS”；不据此主张边界或现场精度。
- 正式总览为授权对象补所属农场标识，农场详情只计当前农场的片区、农田、塘口、设施、有效绑定和告警。隔离库用两个农场及其不同子对象核对归属，原授权过滤不变。
- 修订后 TypeScript、Next.js webpack 构建和 6 项定向测试通过，其中含 D1/D2/D3.1 浏览器回归。未执行数据库迁移，未更新生产运行构建。

## GIS 演示交互修订

八个原有演示农田与塘口采用不同的闭合、不自交 Polygon；内嵌 SVG 字符与颜色区分农田、塘口、水闸、水泵、监测桩、无人机和收割机，面仍保留半透明填充及边界。“＋ 新增演示对象”只在演示模式显示：填写类别、名称和片区后，在地图上单击放置点对象，或逐点绘制面并双击结束。新增项随即进入地图、片区或机动目录和分类统计，详情继续标记合成演示。数据只在当前页面内存，刷新可能消失。

隔离浏览器实际新增水泵、无人机和地块，核对目录、详情、统计与退出后真实数据隔离，浏览演示期间正式业务写请求为 0；边界单测检查 8 个面均闭合、互不相同且不自交。TypeScript 与生产构建通过。实际部署版本见提交对应的运行核对。
