## 2. 状态流转

```
无选中 ──选中对象──▶ 概要卡 ──查看详细资料──▶ 完整详情
                       ▲                        │ 收回概要
                       └────────────────────────┘
概要/完整 ──同类切换──▶ 保持密度与标签（F02）
概要/完整 ──跨类切换──▶ 概要卡 + 基本信息
任意态 ──×/Esc──▶ 关闭（密度重置为概要，视口不变）
```

目录协同折叠（761–1100px 桌面）：详情打开且目录展开 → 系统折叠为「› 目录」拉手；用户手动操作目录后，普通状态更新不再折叠；关闭详情仅恢复"系统自动折叠且用户未干预"的情形。

## 3. 地图定位策略

- 仅选中新对象/片区与「定位当前对象/竣工图范围/全场视图」触发 `view.fit`；展开、收回、标签切换、关闭均不触碰视口（测试以 `data-view-center/zoom` 断言）。
- 定位留白实测：桌面右侧 = 面板实测宽 + 32px；手机底部 = 面板实测高 + 24px（上限 70% 视口高）。
- 选中定位后目标外接框屏幕像素范围写入 `data-selection-px`，测试断言其完整落在面板未遮挡区（不只检查容器宽度）。
- 手机端展开不移动地图；目标被遮时由用户点「定位当前对象」按需重新定位（测试覆盖）。
