## 一、任务目标与结论

用两套**公开 3D Tiles 测试样例**验证现有三维模块能否加载真实世界规模的模型包（离散 LOD 与多层瓦片树两种典型结构），走平台既有的私有上传→登记→校验→鉴权分发全链路，在真实浏览器（SwiftShader WebGL）中渲染。

**结论：通过。** 两套样例均经私有接口完整加载并渲染，LOD 随缩放切换、多瓦片逐级请求、关闭后资源释放且可重开、三视口无横向滚动、全程零外部请求、零页面脚本错误。现有管线可直接承载大疆智图类显式 3D Tiles 成果，但存在文件数上限与逐文件上传两项工程缺口（见第五节）。

## 五、可直接复用的部分（接大疆智图成果时）

- **私有上传→组装→登记→校验→鉴权分发全链路**：`media/uploads` + `terrain/scenes` 的 `registerScene`/`validateScene`，权限按对象 scope 控制，撤回即全资源 403（既有回归已覆盖）。
- **包校验器 `validatePackage`**：已支持 b3dm/glb/gltf/tileset JSON 结构校验、引用闭包、外部地址与凭据拒绝、隐式分块拒绝、64MiB 单瓦片/2GiB 总量上限，可直接校验大疆智图导出的 3D Tiles 目录。
- **私有资源接口** `/api/v1/terrain/scenes/{id}/resources/{path}`：鉴权 + Range 支持，Cesium 直接消费，零外部请求已验证。
- **前端 `cesium-view.tsx`**：本地 Cesium 运行时（无 Ion、无外网）、按需加载、LOD 流式、重置视角、关闭释放、错误降级文案、三视口布局。

## 六、大疆智图（DJI Terra）接入缺口

1. **文件数上限 1000**：`TERRAIN_LIMITS.files=1000`。全场实景模型动辄数千 b3dm，需按地块/架次拆包登记，或评估上调上限（需重议校验与清单存储成本）。
2. **逐文件上传不现实**：当前登记要求逐文件走上传会话。需要「整包 zip 上传 + 服务端解包校验」入口（`media` 已允许 `application/zip`，缺解包与清单生成环节）。
3. **坐标与基准登记**：大疆智图常见输出为 CGCS2000 投影坐标 + ECEF 根变换。登记字段已有 `sourceCrs/verticalDatum/renderCrs/conversionRef`，但转换正确性靠人工申报，无自动核对；接真实成果前需定核验流程。
4. **OSGB 旧格式**：平台只收 3D Tiles；大疆智图新版可直接导出 3D Tiles（b3dm），旧 OSGB 成果需先在加工侧转换。
5. **地形（DOM/DSM）不在本期**：当前仅模型 tileset 展示，椭球底图无色无地形起伏；若需真实地形需另立 quantized-mesh 地形服务议题。
