## 1. 整改前后对照

### 1.1 顶部业务摘要

| 项 | 整改前 | 整改后 |
|---|---|---|
| 农田三项 | 普通文本行 | 三张独立紧凑业务卡（面积/当前生产/生长阶段），空态在卡内 |
| 辅助统计 | 顶部两个「0」计数卡 | 移出顶部（计数随对应标签内容展示） |
| 水闸/泵站 | 文本行 + 计数卡 | 双卡（实际开度/数据上报；泵组概况/数据上报），无计数卡 |
| CAD 面积口径 | 「竣工图施工参考面积」+ 说明 | 不变（R01 口径保留） |
| 未核实批次 | 顶部仅「资料待核实」 | 不变（R02-B 保留） |

### 1.2 基本信息

| 整改前 | 整改后 |
|---|---|
| 对象名称/所属村庄/范围状态与标题区重复展示 | 删除，标题区表达一次 |
| 对象编号/所属农场在基本信息 | 并入折叠「资料依据」（+登记依据/记录时间/版本） |
| 无负责人等字段时无表达 | 合并一条「相关管理资料尚未登记（负责人、主要用途、现场位置说明等登记后在此展示）」 |
| 四类业务字段定义 | 保留（有可信数据时按类逐项展示），未变回通用字段列表 |

### 1.3 业务标签与记录

| 项 | 整改前 | 整改后 |
|---|---|---|
| 农事生产空态 | 与顶部重复两条提示 | 标签内仅一条「暂无生产批次登记。」 |
| 未接入类别 | 显示「暂无相关记录」（误导） | 「该类别记录暂未接入查询，接入后在此展示。」 |
| 「全部」为空 | 「暂无相关记录」 | 「已接入的记录中暂无内容；其他类别暂未接入查询。」 |
| 英文枚举 | 「当前（open）」「已恢复（recovered）」 | 「当前」「已恢复」 |
| 筛选类别 | 农田农事/塘口养殖/闸泵操作（R02-B） | 保留不变 |

### 1.4 底部操作区

- 「查看完整档案 ↗」→ **「查看对象台账 ↗」**（名实相符）。
- 「编辑边界」收进「更多」，仅 `canConfigure` 可见；按钮高度压缩（min-height 32px）。
