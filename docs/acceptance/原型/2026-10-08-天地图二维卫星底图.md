# OpenLayers + 天地图二维卫星底图原型验证

日期：2026-10-08。范围依据：工作目录《第一阶段1原型验证.md》。本页是独立 `/map-prototype`；现有 `/map`、数据库与业务 API 未改动。

## 实现与配置

- `ol` 10.11.0 提供地图、交互与 EPSG:4326 ↔ EPSG:3857 转换。WGS84 初始中心为经度 114.635、纬度 30.250；视图使用 EPSG:3857、初始缩放 13，可自由缩放和平移。
- 影像 `img_w` 与中文注记 `cia_w` 使用天地图真实 WMTS 接口及 Web 墨卡托瓦片矩阵 `w`；注记可独立开关。页面不叠加农场业务对象，也不生成替代影像。
- 浏览器端 `NEXT_PUBLIC_TIANDITU_KEY` 仅设置在 Git 忽略的 `.env.local`；源码、日志与截图均不保存真实值。此类 Key 必然随浏览器瓦片请求公开，须由天地图账户限制适用域名、权限和配额。变更 Key 后需要重新构建 Web。
- 页面显示 Key 缺失或格式异常、浏览器离线、等待超时、影像及注记瓦片累计成功/失败数。跨域图片失败无法从浏览器脚本可靠区分 HTTP 状态；请用浏览器网络面板核对 Key 权限、响应码和网络错误。诊断区不展示 Key 或完整瓦片 URL。

## 实际验证

| 检查 | 结果 |
| --- | --- |
| `pnpm typecheck` | 通过。 |
| `pnpm check:coverage` | 通过；131 条需求、2100 个链接，错误 0。 |
| `node --import tsx --test tests/unit/tianditu-prototype.test.ts` | 2/2 通过；核对 WMTS 行列号与初始坐标转换。 |
| 隔离副本 `pnpm build` | 通过；生成 118 个页面，包含新 `/map-prototype`，原 `/map` 保留。构建副本与运行中的 `.next` 分开。 |
| Chrome 浏览器预览 | 真实登录后的页面加载成功；起点 `114.635000, 30.250000`、缩放 13；缩放、平移和注记切换成功。影像与注记各 35 个瓦片 HTTP 200，记录的错误为 0。私有截图位于 `.local/验证记录/天地图原型-默认.png` 和 `天地图原型-切换注记.png`。 |
| 直接从服务器请求瓦片 | 返回 403，天地图错误码 `301012`，明确说明该 Key 为浏览器端类型；浏览器请求成功，因此此服务器端 403 不代表 Key 失效。 |
| `pnpm test:unit` | 默认并发运行时，既有 `verification-hardening` 的实时报告计时断言失败；本次新增用例通过。改用 `node --import tsx --test --test-concurrency=1 tests/unit/*.test.ts` 后 89/89 通过。该并发不稳定现象不计作全量单测通过。 |
| 正式服务切换 | 新构建已切到 `liangzihu-farm-web`；`/map-prototype` 对未登录请求返回 307 至 `/login`，登录页返回 200，容器正常运行。交互与真实瓦片验证是在相同构建的隔离预览环境完成。 |

本次没有测试真实地块边界、现场坐标精度、影像时效或天地图长期可用性；地图上的影像和注记来自天地图在线服务，不是农场已验收的测绘资料。

## 后续

在决定是否接入现有 `/map` 前，应确认天地图 Key 的域名与配额策略、服务条款、现场设备网络、地图坐标来源和影像使用范围；再单独设计业务图层叠加与权限，不以此原型直接替代现有对象地图。
