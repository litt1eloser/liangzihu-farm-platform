# 第一阶段 1：二维卫星底图原型验证报告

日期：2026-10-08
对应计划：[第一阶段1原型验证.md](../../plans/第一阶段1原型验证.md)

## 结论

已在 Ubuntu 主机 `luminous` 的 `/data/wfx/liangzihu-farm-platform` 部署独立原型。登录后通过本机 [原型页面](http://127.0.0.1:3100/map-prototype) 查看天地图真实卫星影像，能够平移、缩放和切换中文注记；初始中心为东经 114.635°、北纬 30.250°。原有 `/map`、数据库和业务 API 未改动。用户已看到页面；按本轮决定，暂不加入标点功能。

## 主要改动

- 新增 `src/app/(platform)/map-prototype/` 页面及样式、`src/modules/map-prototype/tianditu.ts` 瓦片地址与坐标工具、`tests/unit/tianditu-prototype.test.ts`。
- 增加 OpenLayers 依赖，更新 `package.json`、`pnpm-lock.yaml`、`.env.example`、`README.md`、`docs/README.md`、`CHANGELOG.md`，并在仓库 `docs/acceptance/原型/` 保存详细验收记录。
- 浏览器端天地图 Key 只配置在服务器 Git 忽略的 `.env.local`。为解决实际登录问题，服务器恢复账号密码登录；本机设置了 SSH 转发自动重连。

## 实际验证与问题

- 类型检查、生产构建、原型单测 2/2、串行全量单测 89/89 通过。Chrome 预览中影像和注记各有 35 个瓦片返回 HTTP 200，平移、缩放、注记切换正常。
- 正式服务用初始账号完成登录并签发会话；带会话访问 `/map-prototype` 返回 HTTP 200。本机登录页也返回 HTTP 200。
- 默认并发单测触发既有 `verification-hardening` 计时断言失败，串行复测通过。天地图 Key 为浏览器端类型，服务器直接请求瓦片会收到 403；浏览器请求正常。
- 尚未验证现场地块坐标、影像时效、长期服务可用性或业务图层叠加。原型当前不能标点，也不会保存地图位置或业务数据。

## 下一阶段建议

先核实天地图 Key 的域名限制、配额与现场网络，以及地块坐标来源。若后续需要标点，应先明确仅临时标记还是持久保存，再单独设计数据结构、权限与验收；不要直接把本原型替换现有业务地图。
