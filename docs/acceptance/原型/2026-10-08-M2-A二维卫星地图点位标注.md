# M2-A 二维卫星地图点位标注验收

日期：2026-10-08。范围依据：[M2-A 计划](../../plans/M2-A：二维卫星地图点位标注.md)。入口仍为 `/map-prototype`；正式 `/map`、三维地图、地块边界和设备台账未改动。

## 实现

- 新增 `044_satellite_draft_points.sql`：`satellite_draft_points` 以 `geometry(Point,4326)` 保存位置，`ST_MakePoint(经度, 纬度)` 入库，`ST_X` / `ST_Y` 读回。点位绑定 `owner_id`，含名称、备注、版本和请求幂等键；创建、修改、删除写入 `audit_events`。不使用 `flight_annotations`。
- `/api/v1/map-prototype/points` 和 `/api/v1/map-prototype/points/[id]` 沿用会话鉴权、同源写入校验、事务、统一错误响应和输入长度限制；按当前用户过滤读写。专家角色不能访问此个人草稿入口。重复创建请求按请求键返回同一条记录，修改和删除检查版本。
- 地图默认浏览；选“标点”后点击空白位置出现空心临时标记和编辑表单。成功保存才出现红色标记及中文名称；点击既有标记可编辑或确认删除。Esc 和“取消”不写库；网络失败保留表单与临时标记。输入法组合期间不会因 Enter 提交，地图实例在表单输入时保持稳定。

## 限制与后续

点位是当前账号的私有草稿，没有对象授权共享、现场测量精度确认或批量导入；列表至多读取最近 1000 条。浏览器依赖天地图在线瓦片与当前 Key 权限；服务端直接请求浏览器端 Key 的瓦片仍可能收到天地图 403。M2-B 线段、M2-C 多边形与三维标注均未开发。用户手动验收后，再依据现场坐标来源决定是否建立正式业务点位流程。
