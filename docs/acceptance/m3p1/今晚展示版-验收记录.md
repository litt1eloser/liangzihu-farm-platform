## 三、联调中发现并已修复的问题（提交 `275a90a`）

1. **手机端（≤760px）三维视图整区空白**：`farm-3d-view.module.css` 的 `.root` 原为 `position:absolute;inset:0`，移动端 `.mapShell` 高度由二维 `.map` 容器撑开，切 3D 后 `.map` display:none 导致父容器塌陷为 0 高，三维画布、工具栏、提示条全部不可见。修复：`.root` 改为文档流内 `height:100%` 并沿用二维地图的移动端高度规则（`calc(100dvh - 250px)`，min 500px）。修复后 390×844 下三维影像、边界、工具栏、提示条全部正常。
2. **≤1024px 地图工具栏按钮文字竖排**：`mapToolbar` 无换行策略，按钮被压缩导致文字逐字换行（二维模式同样存在，3D 按钮加重拥挤）。修复：`mapToolbar` 增加 `flex-wrap:wrap`，按钮 `white-space:nowrap;flex:0 0 auto`。修复后 1024/390 全部横排可读。

修复后 `tsc --noEmit`、`next build`、完整浏览器联调全部重跑通过。
