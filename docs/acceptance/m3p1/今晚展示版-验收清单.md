# M3-P1 今晚展示版：验证与发布边界

开发分支：`m3-p1-3d-demo`，基于 `m3-p0-3d-model-loading`。本轮只加入 `/farm-overview` 的 Cesium 三维只读视图，不改正式农业对象和测绘数据。

## 已提交的功能（待浏览器验证）
- 原工作台工具栏内 2D / 3D 切换；返回 2D 后保留农业资源树及原有业务详情。
- 三维视图采用现有本地 Cesium 运行时、天地图 WMTS 影像地址；初始采用倾斜视角，参考椭球不代表实测高程。
- 读取 `/api/v1/farm-overview` 农业对象几何，支持面/线/点可视化、点击选中、资源树选择后镜头定位。
- CAD 竣工图参考图层沿用已配置的分类显隐，默认土地平整可见，道路/农渠隐藏。
- 「全场视图」触发三维区域定位；三维未实现旧的 CAD 整体范围工具，已暂时禁用该按钮。
- 错误时显示返回二维入口；暂不接入真实 3D Tiles、DEM、三维编辑、实体设备控制。

## 必须由 Kimi 在 luminous 验证（未执行前不得宣称通过）
1. `pnpm typecheck`、`pnpm build`。
2. 启动独立预览服务（不覆盖在跑端口、不更改生产数据库），管理员打开 `/farm-overview`。
3. 点击 3D：实际 Cesium 画布出现，天地图卫星瓦片能加载，授权的农业边界/CAD 参考能绘制；无数据时不伪造农田。
4. 在左侧资源树选择带合法几何的农田，三维相机定位，右侧仍为原 V1.2 卡片；点击地图农田可更新同一业务详情。
5. 「全场视图」、复位视角、图层开关、返回 2D 后原地图恢复，反复切换检查 WebGL 上下文和浏览器 console。
6. 检查 1440、1024、390 宽度：工具栏不遮挡，右侧详情和图层面板能够操作；至少各留一张截图。
7. 重点核对真实天地图 WMTS 模板（z/x/y）、WebMercator 与 PostGIS 经纬度的坐标对齐；缺 Key、无 WebGL、无网时优雅回退。
8. 不允许通过为测试方便而写入虚假的农田空间数据，也不上传样例龙/Obj2Tiles 到梁子湖实际经纬度。

## 展示稿建议
建议优先演示：已登记对象的二维卫星影像 → 点击 3D → 旋转倾斜/缩放 → 选择一块农田 → 右侧查看原业务概要 → 返回二维。明确说明三维底面是参考椭球，尚无梁子湖实测地形或无人机实景模型。
