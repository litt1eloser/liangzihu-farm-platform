# 农场空间总览 D1 工程验收记录

日期：2026-10-09。范围依据：[产品 v1.0](../../../计划/产品定义与最终开发边界%20v1.0.md)及[修订后的 D0 方案](../../../报告/空间化农场总览-D0只读审计与实施方案.md)。本记录只覆盖 D1，不代表 D2 或现场验收。

## 实施范围

- 新增独立 `/farm-overview` 页面及平台导航入口；左侧按**已有正式对象类型**列出已授权对象，提供名称/编号搜索和定位。
- 复用 OpenLayers 与天地图卫星影像、中文注记；用现有 `/api/v1/map` 的授权对象边界绘制。无几何对象保留在目录，不生成坐标。
- 对象详情采用桌面右侧覆盖抽屉、手机底部抽屉；显示对象代码、边界核实状态、版本和原页面入口；关闭不重置地图视口。
- 保留 `/map`、`/map-prototype` 和 `/terrain`。未新增迁移、动态村庄管理、设备实时接入或业务写入接口。

## 实际验证

| 检查 | 结果 |
|---|---|
| TypeScript `tsc --noEmit` | 通过 |
| Next.js 16.3.8 `next build --webpack` | 通过，产物包含 `/farm-overview`；独立工作树共用依赖的 symlink 超出 Turbopack 根目录，故用 webpack 构建；线上构建方式未修改 |
| Playwright 浏览器用例 `tests/acceptance/farm-overview-browser.test.ts` | 通过；隔离测试 schema 中创建合成农田、无边界塘口和无权对象，检查桌面搜索定位、抽屉开关、手机目录/底部详情、无横向溢出、浏览器脚本无错误 |
| 权限 | 工人账号的页面和 `/api/v1/map` 都不包含无权对象；只有对象 read 授权而无资源授权的专家账号在地图 API 与页面中均看不到对象 |
| 实际浏览器影像 | Ubuntu Chrome 中截图可见天地图影像及中文注记，来源是测试环境配置的浏览器端 Key；网络与 Key 配额仍需正式环境复测 |
