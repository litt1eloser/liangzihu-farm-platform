任务：为梁子湖智慧农业平台实现 OpenLayers + 天地图二维卫星底图的最小验证原型。

要求：

1. 检查现有 Next.js / React / TypeScript 项目结构，复用现有环境。
2. 使用 OpenLayers，加载国家天地图的卫星影像图层和地理注记图层。
3. 天地图浏览器端 Key 从本地环境变量读取，不提交真实 Key。
4. 地图初始中心为经度 114.635、纬度 30.250，支持自由缩放、平移、切换注记图层。
5. 正确处理 EPSG:4326 和 EPSG:3857 的坐标转换。
6. 创建独立测试页面，暂不替换现有 `/map`，不修改数据库和现有业务 API。
7. 对影像加载失败、Key 无效、网络错误等情况提供可观察的诊断信息。
8. 依照仓库规范运行类型检查、构建及相关测试，并记录验证结果。

仅完成卫星底图验证，不开发标注、测距、三维等功能。不使用虚构的地图影像替代实际接口。

完成后报告修改文件、实际运行结果、存在的问题和下一阶段建议。
