# 梁子湖竣工图：实际提取成果与使用边界

**复核日期：2026-10-28**  
**来源：5 份 DXF、5 份对应单页 PDF；另有 5 份 DWG 作为原始备查。**  
**本成果仅为离线研究及隔离测试包；未连接或改动梁子湖生产数据库。**

## 一句话结论

**工程图纸中已经提取出可以实际查看、测量和追溯的农业几何；但不能据此立即认定是真实经营地块，也不能把 CAD 坐标直接贴上天地图。** 当前几何可用于独立的 GIS 测试图层，全部 5 张图的绝对地理定位均为 **L3（内部比例有依据、绝对位置尚未得到独立核验）**。

## 2. 提取数量与可信程度

**候选线面几何 386 条：A 级 67、B 级 277、C 级 42。** 其中 **137 面、249 线**，存于 `09-提取的空间数据/CAD候选几何_坐标参考未知.gpkg`，由两个图层组成。

- **A 级**：图层语义明确、面几何有效、图内有可一对一对应的平整范围编号。它仅证明**施工平整范围的图内识别**，不证明经营田块身份、权属、现状或绝对经纬度。
- **B 级**：几何可读取、用途有较强线索，但名称、对象边界或归属未完全确认；适合审核，不宜自动升为真实资产。
- **C 级**：地类图斑、部分清淤/施工范围、异常或仅符号化的对象；不能直接纳入农业资产数据库。

补充数据包括 **6,877 条原始 CAD POINT（含 Z 数值）**、**343 个与水利设施有关的 CAD INSERT 图块参照**。343 个图块中 279 个的原始插入点处于主体范围，另 64 个插入点明显离群。**没有一个块参照被认定为现场已核实的泵站、水闸或设备点位。** 所有这类点位与高程均在独立 GPKG/CSV 中标注为 *未核验*。

各类线面：土地平整施工范围 70、田埂田间道 147、沟渠 71、道路 38、项目施工边界 16、塘口清淤施工范围 6、土地利用图斑 36、泵站候选 1、疑似施工范围 1。**这些是分类后的 CAD 几何记录数，不是去重后的实体资产数量。**

## 4. 能不能确定五图在梁子湖的实际位置

**还不能作为已核实位置使用，五张均定为 L3。**

图签 `TK` 层确实写有「2000 国家大地坐标系」和「1985 高程基准」，这对坐标识别有实质帮助。初步按 **CGCS2000 3°高斯投影、中央子午线 114°（EPSG:4547）**、CAD X 为东坐标、Y 为北坐标试算，可得到约 **114.617–114.626°E、30.250–30.262°N** 的候选区域。这和鄂州梁子湖区的区域量级相容，但**尚未通过至少三处可靠道路、桥涵或沟渠控制点，与正式地图逐点验证**，因此没有可信的配准残差，也不把这些候选经纬度写入 GPKG。

梁子湖区人民政府 2025 年《沙湾村村庄规划（2021–2035）》明确列出庙下刘湾、新屋湾、毛家湾、张家湾、谭塆沈湾等自然湾；这确认地名归属，**不能作为精确测量控制点**。出处：<https://www.liangzh.gov.cn/dzdt/gsgg/202507/t20250731_716898.html>。行政地名与图纸的拼写差异，均保留原始文件名并另行说明。

**地图图片使用边界**：`08-图纸与地图对照图` 提供的是 PDF 竣工图与 CAD 提取图形的**并列对照**，还有基于 EPSG:4547 的候选位置**示意图**；它们**不是已经与卫星影像完成精确配准的叠图**，也没有人为编造对照控制点。

## 5. 现在可以怎么用，哪些不能用

**可立即用于独立 GIS 测试环境**：CAD 原坐标下的线/面 GPKG、保留原始点高程的点 GPKG、候选对象 CSV、PDF—CAD 对照图；用它们测试图层、筛选、选中、详情、面面积/线长度，以及数据审核交互。

**必须人工复核后再考虑入真实地图**：A/B 平整范围的业务身份、道路/沟渠中心线或边界性质、清淤范围与塘口本体的关系；Z 点是否真是测量高程以及采用哪个高程基准；设施符号的实际数量和位置。

**现阶段不可使用**：未审查的经纬度、把图中平整面直接当经营田块、把 INSERT 数量直接当设备数量、把 CAD Z 直接当高精 DEM、依据临近线段直接推断水流方向。不得在正式 PostGIS/天地图生产图层创建这些不确定的空间资产。

## 6. 最少还缺什么

优先只补两类证据：

1. **出图/竣工测量单位的一页坐标说明**：投影、中央子午线、带号/假东、是否使用地方独立基准或平移旋转；若附带原始控制点/检查点更好。
2. **至少 3–5 处分布较开、可在 CAD 和真实影像/控制点资料中一一辨认的固定地物**，如道路交叉口、桥涵和沟渠汇流；最好留出独立检查点计算位置残差。

若进一步要正式登记设备，还需要针对水闸/泵站/涵管的**设施图块与现场台账/坐标**核验；必要时回到原 DWG 检查异常块参照，而不是先索要全场重测资料。

## 7. 导入梁子湖现有平台的合理顺序

这一步先**不改生产数据库**。在独立 QA 项目中，以 `来源图纸 SHA256 + 文件名 + CAD handle + 图层` 为追溯键，以独立 UUID 作后续资产身份，保留**原始几何、原始文字、标注依据、可信级别、坐标验证状态和审核版本**。施工范围与经营田块、道路/渠中心线与真实占地边界、设计/竣工符号与现存设施，必须分开管理。待定位 L1 且业务身份审核通过，再把相应几何与原有 `objects`、边界版本或 `device_positions` 建立已审查关系；不要另造一套独立设备主数据。

### 可重复运行及重要限制

原始 DXF/PDF 均只读；处理程序将成果写入独立成果目录，未覆盖原始资料。复现时将两个压缩包按本项目原工作路径解压，并按 `10-提取与验证脚本` 编号执行；脚本依赖此交付环境的 `/mnt/data` 路径，可以改成工程部署路径，但源文件 SHA256 应保持一致。**脚本目前主要解析模型空间的源实体，设施相关嵌套块未完成全部世界坐标重建；因此本交付明确标注设施图块点为 C 级候选，不宣称现场完整设施普查。**
