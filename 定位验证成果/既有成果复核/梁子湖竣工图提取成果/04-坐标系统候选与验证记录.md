# 梁子湖 CAD 坐标候选与验证记录

**状态：截至 2026-10-28，绝对坐标未确认；禁止把候选经纬度作为真实地理位置发布。**

## 一、可直接观察的事实

- 5 份 DXF 的图签附近，均有相邻文字 `2000` + `国家大地坐标系`，以及 `1985` + `高程基准`。对应 CAD 模型空间 `TK` 图层中的独立文字实体，而不是从文档题目推测。
- 五图主体实体存在相近的数值坐标，横向约 558,000–561,000，纵向约 3,347,000–3,350,000，跨图相对位置具有可比性。**这个数值范围并不直接证明投影方法。**
- 五份 PDF 的图例均重复 `X 3285837.364`、`Y 611974.308`。这是反复出现的**图例示例文字**，不能视为五张图共用的实测控制点，也不能据此将 CAD 坐标整体平移。
- DXF 文件的 `$INSUNITS` 不一致：张家湾写 `1`（AutoCAD 标准表为英寸），其余四份为 `0`（未声明）。但张家湾多个线长度按“1 CAD 坐标单位≈1 m”与图上米制长度相吻合。因此不能机械地按 `$INSUNITS=1` 将整图乘以 0.0254。
- 多个水闸/泵站/涵管 `INSERT` 原始插入点出现明显离群值，如横坐标约 **-38,008,000**。这类图块坐标不应直接当设施位置；需要再检查块参照、转换历史、坐标变换和 DWG 源文件。其它地块轮廓和道路坐标通常没有这个异常。

## 二、外部地名证据

鄂州市梁子湖区人民政府 2025-07-07 公示的《沙湾村村庄规划（2021–2035）》明确列出沙湾村的自然湾 **毛家湾、庙下刘湾、张家湾、谭塆沈湾、新屋湾**，与五张图纸的地名一致。官方资料还说明沙湾村位于梁子镇东北部，东邻余湾村，西临梁子湖，南邻长岭，北邻磨刀矶。这确认了行政归属和别名，**并非精度足以用作图纸控制点的坐标证据**。

资料来源：
- https://www.liangzh.gov.cn/dzdt/gsgg/202507/t20250731_716898.html （2025-07-07 政府公示，包含自然湾名录与规划区地图）
- https://www.liangzh.gov.cn/lzhxxgk/bmptlj/lzz/swcwh/cjwgk/202207/t20220713_484770.html （2022-07-13 沙湾村简介，提到庙下刘、张家湾、毛家湾）
- https://epsg.io/4547 （3 度带中央子午线 114° 的 CGCS2000 投影定义与适用范围）

名称核对：`庙下流` 很可能是 `庙下刘湾` 的误写；`谭湾沈湾` 对应官方 `谭塆沈湾`；`ABCDEFD区` / `ABCDEF` 是施工分区命名，不能按独立行政村定位。以上只核对名称语义，不自动重命名原始文件。

## 三、坐标解释对比

逐图使用候选几何的**加权质心**计算几个假设的试验经纬度，完整记录在 `09-提取的空间数据/坐标解释候选试验.csv`。权重仅为演示候选区域中心，不作为测绘控制。保存的 GeoPackage **未赋予 EPSG:4547 或 WGS84**。

| 候选解释 | 结果 | 现有判断 |
| --- | --- | --- |
| CAD X 东向、Y 北向；CGCS2000 3°高斯投影，CM=114°（EPSG:4547） | 点云落在约 **114.617°–114.626°E、30.250°–30.262°N** | 地域量级、官方地名与共同平面图纸关系**相容**；待找道路/桥梁/沟渠控制点核验，属优先候选 |
| CAD X 东向、Y 北向；CM=117°（EPSG:4548） | 约 117.6°E | 明显偏离梁子湖目标区域，不优先 |
| CAD X 东向、Y 北向；CM=111°（EPSG:4546） | 约 111.6°E | 明显偏离，不优先 |
| CAD 两轴交换，然后按 EPSG:4547 转换 | 投影运算越界或产生无效区域 | 轴顺序与数值量级不相容；不能凭测绘 X/Y 叫法直接交换 |
| 地方独立坐标或平移/旋转后的 CGCS2000 | 尚未计算唯一变换 | **未排除**；需要多个同名、稳定的真实地物或测量控制点 |

注意：本次并**未取得至少三处可验证的、分布较开的 CAD—实地同名控制点**。因此没有合理的残差/RMSE 数值，不能填写虚构精度，也不能宣称与卫星图完成配准。政府村庄规划图只能完成粗略范围核对，其图片并没有提供公开的逐像素地理坐标基准。

## 五、最少补充资料与建议核验次序

1. 优先询问**竣工测量坐标系统说明**，至少包含是否为 CGCS2000、3°还是6°带、中央子午线、是否带号、是否有地方平移/旋转；顺便取得 1 份坐标检查点列表。通常只需要一页技术说明。
2. 如果没有投影说明，选一张重点图，找 **3–5 个相隔较远的稳定地物**（道路交叉口、桥涵、沟渠交汇/泵站角点）及其经过核验的 CGCS2000 坐标；试算相似变换并把剩余点用于独立误差检验。
3. 对 `INSERT` 水闸/泵站位置，优先从原始 DWG 或出图方确认图块坐标变换，避免把渲染正确但插入点异常的图块当测绘点。
4. 基准确认后再对比天地图影像，同时考虑工程日期与影像采集时间差。保留点对截图、残差、变换参数、版本与资料来源。
