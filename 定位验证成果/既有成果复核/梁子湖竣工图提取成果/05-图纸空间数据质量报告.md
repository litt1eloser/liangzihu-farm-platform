# 图纸空间数据质量报告（初次提取）

## 统计口径

2026-10-28 对 5 个 DXF 模型空间进行了**保守选层**，仅抽取图层语义相对明确、坐标处于主体范围、超过基本长度/面积阈值的实体。每条 CSV 代表**候选 CAD 几何记录**，不等于独立真实资产；多条线路可能描述同一条道路的不同侧边。背景地籍地貌层 `JMD/DMTZ/GCD/DM` 中大量线、点、影线未做农业地块身份强制分类。

- 模型空间共 **37,284 个 CAD 实体**，这不等于农业对象数。
- 数据包提取 **386 条候选几何**，其中 **67 A、277 B、42 C**；点 0、线 249、面 137。A 为图层语义、边界几何和一对一文字同图对应（本次主要为平整范围线），**不表示绝对位置已经确认**。
- 70 条“平整范围线”候选面中：67 条标注对应且几何有效（A）、2 条有效但无一对一编号（B）、1 条有自交（C）。另有少数过小线/符号等不纳入面积统计。
- 除此之外仍有道路、沟渠、田埂、清淤范围、施工区边界等 **B 级候选**。不能把 B 级道路图形数直接称为道路条数。

## 六类核心问题

**1. 面闭合、自交**：标记为 `平整范围线` 的原始条目不能全部当有效 Polygon。ABCDEF 分区 handle `2CF9` 对应 `平-14`，存在自交；不得自动 make_valid 后取代原始边界。ABCDEF 分区还有土地利用图斑 handle `1DBA` 自交。

**2. 平整范围面重叠**：ABCDEF 分区 `2CEE` 与 `2CEF`（原文 `平-1`、`平-2`）面积相交约 **25.229 CAD平方单位**。两者可在无修复的原图里查看；不应自动相加为不重复的地块面积。详见 `09-提取的空间数据/平整范围跨图及内部重叠.csv`。

**3. 重复图形**：几条跨图纸不同用途的参照、图例和图形可能重复。本次捕获了 ABCDEF 分区若干完全重复几何记录，它们保留在 C 级或疑点清单，不能简单重复入库。重叠统计仅针对已经纳入的平整范围面，未对全部 37,284 个背景实体进行跨图拓扑覆盖。

**4. INSERT 和设备位置**：`6-2水闸` 在 DXF 中有 19 个 INSERT 实体；部分泵站及涵管图块也使用 INSERT，但是大量插入坐标达数千万的离群值。解析时没有把它们导出成“真实水闸位置”；**0 个设施点达到可独立 GIS 定位条件**。PDF 确实画有水闸、泵站、涵管、井和沉砂池图示，但需要块参照/原DWG人工复核，且竣工图位置不等于现在设备仍在现场。

**5. 道路/沟渠的表示**：`3-2生产路` 等图层常见线段代表线状工程；闭合道路带面也可能代表施工边缘。它们没有依据就不得作为道路中心线或实际占地范围。道路标注 64、164、267、285、393 m 等有对应线长支持，但不代表所有长度均经过现场量测；沟渠中心线不能推导渠宽，必须有对应的宽度标注才行。

**6. 面积及“田块”概念**：`平整范围线` 是施工平整区，并非经营田块、地籍产权地块或现存田埂。`水田填充`、`JMD`、`DMTZ` 很多是地图背景/地类表达，不应利用颜色和封闭状态批量误认为独立田块。CAD 的 `HATCH` 还可能带孔洞或图例填充，本次没有用 HATCH 泛化构建更多“农田”。

## 高程点、设备图块的附加质检（新增）

- 从原始 DXF 模型空间逐条读取到 **6,877 个 `POINT` 实体**，保存原始 CAD X/Y/Z、来源图纸、图层和 HANDLE，独立导出 `CAD原始测绘点_坐标与高程未确认.gpkg` 及 CSV。谭湾沈湾 `DM` 图层包含其中 **5,821 个点**；所有点的 Z 原值范围约 **-5.848 ～ 27.751**。POINT 可能包括地貌/高程测点，也可能包括工程辅助点；没有根据图层名称批量认定为实测高程或有效 DEM 采样。
- 筛出 **343 个与泵站、涵管、水闸、井等有关的 `INSERT` 图块参照**。其中 **279 个参照的原始插入 XY 落在主体包络内**，作为独立的 `设施图块位置候选_未核实.gpkg` 保存，**仅标 C 级**；另有 **64 个插入点明显离群**。许多涵管结构在 CAD 中由多个块片段构成，因此 343、279 均不是实际设施数量。完整原位、变换与旋转信息见 `设施图块与插入位置待核实.csv`。
- 由于块定义存在嵌套、匿名块、缩放/旋转、布局或异常变换，本次并未把这些插入坐标提升为“现场核实设备位置”；已保留原插入参数和来源，以便交由设计单位复核。
- `06-可疑对象与待核实清单.csv` 为**重点异常记录（110条）**：42 条 C 级主几何候选、2 条无对应编号的 B 级平整面、2 条重叠 A 级平整面以及 64 条离群块参照。它不是所有待核实内容的全集；其余图块的 279 个 C 级插入候选在 09 目录的原始完整清单里。

## 已验证的面积与长度

- 庙下流：PDF 平整田块 **151.45 亩**；25 个可计量平整面合计 **151.451 亩**，误差约 **+0.0004%**。使用平方米假设下的换算（1 亩=2000/3 ㎡）。属于强单位及几何对应证据。
- 新屋湾+毛家湾：两组平整面积文字合计 **144.05 亩**，保守提取的 25 个平整面合计 **140.074 亩**，差 **-2.760%**。由于尚未逐片核对对应边界，这不是严格同一范围的面积差，更不能据此自动调整顶点。
- 张家湾：`0` 层 `B253C` 闭合面约 **61.215 亩**，与 PDF `施工面积：61.2 亩` 差 **+0.0242%**，但图层没有施工语义，另有相近边界 `4F56A` 约 68.44 亩，**因此仅列 C 级候选，待人工确认哪个边界对应施工范围**。
- 谭湾沈湾：PDF `施工面积：54.8 亩`，暂未发现能够与之唯一对应的、语义充分的闭合边界。**面积校核未完成**。
- 谭湾沈湾：DXF 渠线 handle `31D7C` 长 **204.425 m**，与 PDF `205 m` 偏差 **-0.281%**；道路 handle `31D93` 长 **392.833 m**，与 PDF `393 m` 偏差 **-0.043%**。
- 张家湾：四条 164/285/267/64 m 道路线的对应 CAD 长度分别为 163.438/284.895/266.573/64.057 m，误差约 -0.342%/-0.037%/-0.160%/+0.088%。

**当前没有的证据**：真实对地的多点配准残差、卫星影像实地点对、现场设备复核、沟渠断面或高程竣工精度记录。`1985高程基准` 的图签信息并不自动证明所有散点高程都经过了统一高程检查。
